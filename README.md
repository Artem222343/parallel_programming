## 1. Цель работы
Параллельную версию программы на MPI необходимо также запустить на суперкомпьютере «Сергей Королёв».

## 2. Условия экспериментов
* **Размеры матриц:** 200, 400, 800, 1200, 1600, 2000
* **Число потоков:** 1, 2, 4, 8, 16

## 5. Выводы
По результатам экспериментов видно, что увеличение общего числа вычислительных потоков значительно ускоряет процесс перемножения матриц.

Для матриц небольшого размера (вплоть до 800x800) наилучшие результаты дает конфигурация на 8 потоков. Использование 16 потоков на малых объемах данных оказывается менее эффективным.

Однако для ресурсоемких задач (большие матрицы 1600x1600 и 2000x2000) накладные расходы нивелируются огромным объемом математических операций, поэтому наиболее эффективным оказался запуск с 16 потоками.

Базовая однопоточная версия ожидаемо показала наихудшее время выполнения на всех исследуемых размерах матриц.
